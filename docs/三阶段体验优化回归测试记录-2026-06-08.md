## 3. 发现的问题

1. 自动化快照没有暴露排查记录管理页底部「生成通知书」按钮，导致分享弹窗未能自动点到。
2. 报告检查缺项目前增强到“点击缺项打开对应记录详情”，还没有做到字段级自动滚动到「整改期限 / 责任人 / 项目名称」输入框。
3. 当前测试数据没有覆盖今天到期、已逾期、已闭环三种期限状态组合。
4. 导入确认入库未在本轮自动化中完整执行，避免污染已有草稿数据。

## 4. 修复的问题

本轮顺手修复 / 增强：

- 报告检查缺项支持点击打开对应记录详情。
- 导出前检查弹窗的「去补充」会打开第一条相关记录详情。
- 用户点击分享并允许导出时，会记录通知生成时间。
- 闭环时间线「生成通知」节点优先显示真实导出 / 分享时间。
