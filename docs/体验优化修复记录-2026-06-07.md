## 修复内容

### 1. 导入箱信息不完整时防误入库

- 复用导入核对页已有的 `attentionFieldCount`、`overallStatus`、`needsAttention` 等状态。
- 新增核心隐患内容校验：没有隐患条目，或隐患/整改项缺少“问题描述 / 整改要求”时，视为不可入库。
- 字段缺失时，“确认入库”按钮置灰不可点。
- 底部固定提示：“请先补充必要信息后再入库”。
- 已入库草稿进入核对页时显示“已入库”，按钮禁用，避免重复入库。
- 已入库状态下不再把历史缺失字段作为待入库阻断信息展示，减少“已入库但仍需补充”的矛盾感。

### 2. 导入核对页反馈增强

- 在底部操作栏上方增加固定状态提示区。
- 入库成功后显示：“已成功入库，可在排查记录中查看”。
- 入库失败时显示：“入库失败，请检查信息后重试”并附带错误详情。
- 保存草稿、重新识别、仅保存原文件在已入库状态下禁用，避免重复或状态回退。

### 3. 弹层关闭入口

- 报告模板编辑器左上角新增“关闭”按钮。
- 导入草稿核对页左上角新增“关闭”按钮。
- 导入原文预览、导入文本预览新增“关闭”按钮。
- 原有报告预览、全屏预览、整改相关弹层已有“关闭 / 完成 / 取消”，未做额外结构调整。

### 4. 正式报告字段智能优化选择体验

- 将“存在问题 / 整改要求 / 整改依据”的角落小开关改为清晰的复选按钮组。
- 主按钮文案根据选择数量变化：
  - 未选择：请选择优化项
  - 选择 1 项：智能优化 1 项
  - 选择 2 项：智能优化 2 项
  - 选择 3 项：智能优化 3 项
- 未选择时仍保留原提示：“请先开启优化项”。
- 未改变原 AI 优化逻辑，只调整选择交互和文案。

### 5. 安全教育人数为空提示

- 保存安全教育记录时，如果“参加人数”为空，会先弹出提示：
  - 标题：参加人数未填写
  - 内容：未填写参加人数时，将按 0 人次计入统计。
  - 按钮：继续保存 / 返回填写
- 用户选择继续保存后，仍按 0 人次保存。
- 安全教育入口文案改为区分教育次数和参加人次，并提示未填人数记录。
- 月度总结中将“教育次数”和“参加人次”拆成两个统计卡片。
- 月度总结和月报草稿会提示有教育记录未填写参加人数。

### 6. 首页最近记录长文本优化

- 首页最近记录不再直接展示完整导入原文或离线记录模板。
- 对离线/手工记录优先提取“现场简述”后的核心内容。
- 最近记录摘要压缩到约 72 字以内并加省略号。
- 展示重点保留为“部位 / 问题摘要 / 风险等级 / 整改状态”。

### 7. 退出登录后信息残留修复

- 退出 Apple 登录时同步清除 Apple 标识、云端 accessToken、会员状态、AI 额度、用户 ID、姓名和昵称。
- 增加登录会话版本保护，退出后尚未完成的云端请求即使返回，也不会再把旧会员/额度写回页面。
- 未登录状态下如果发现残留云端令牌，会在“我的”页进入时自动清理，避免出现半截登录态。

### 8. 登录入口临时关闭

- “我的”页改为本地使用模式，暂时隐藏 Apple 登录入口、会员刷新、购买月会员和开发模拟续费入口。
- 账户区显示“会员状态：暂未启用”“AI 额度：本地模式”，避免用户被沙盒账号登录流程阻断。
- 本地模式下不再自动刷新云端账号，也不会清空用户在身份信息中填写的姓名和昵称。

## 遗留问题

- 报告模板编辑器目前只增加了明确关闭按钮，尚未实现未保存变更检测和“保存并关闭 / 放弃修改 / 继续编辑”的三选确认。
- 导入箱字段缺失禁止入库已在代码中实现，但本轮模拟器只有已入库历史样本；后续建议用新导入文件再做一次完整未入库样本验证。
- 首页最近记录摘要仍依赖现有字段质量；如果原始问题描述本身很长且没有结构化地点，仍只能做截断展示。
