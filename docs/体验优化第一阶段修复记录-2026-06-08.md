# 体验优化第一阶段修复记录

日期：2026-06-08  
范围：安全员首次使用信任感与反馈感优化

## 已完成

### 1. 导入文件点击反馈

- 点击“导入文件”后立即显示“正在打开文件选择器…”提示。
- 如果文件选择器没有明显响应，会提示用户可从系统文件 App、微信或其他 App 分享到安全大师导入。
- 导入失败提示增加兜底路径，避免用户误以为按钮坏了。
- 导入箱空状态增加“分享导入”说明。
- PDF 提取文字很少时，在文件卡片上提示“可能是扫描件，文字识别结果可能不完整，请核对后再入库”。
- 文件卡片状态文案调整为更直观的“已入库”“导入失败”等。

### 2. 导入草稿核对缺字段定位

- 核对页顶部增加整体判断：已入库、可入库或需补充。
- 缺字段时显示“待补字段”标签，例如项目名称、通知编号、通知日期、整改期限等。
- 点击待补字段标签会自动滚动到对应输入区域。
- 底部入库提示从笼统“请先补充必要信息”改为“还差：通知日期、整改期限”等具体原因。
- 日期/期限字段增加日历图标和日期入口感。
- 已入库草稿继续禁用重复保存和重复入库。

### 3. 照片添加确认感

- 隐患现场照片添加后显示“已添加主图/副图”提示。
- 现场照片缩略图显示“主图/副图”和导入时间。
- 点击现场照片可以放大预览。
- 预览页支持关闭、删除、替换照片。
- 照片添加失败时弹出“照片添加失败，请重新选择或检查相册权限”。
- 立即整改照片预览增加“整改后”标签。
- 相册权限文案改为“用于选择和保存隐患排查、整改照片。”

### 4. 正式资料字段关闭自动纠错

- 隐患识别页的项目名称、项目简称、检查人、隐患地点关闭自动纠错和自动首字母大写。
- 隐患详情页的项目名称、检查人、部位/地点、正式报告字段关闭自动纠错。
- 导入核对页的项目名称、通知编号、单位、日期、责任单位等字段关闭自动纠错。
- 报告模板页的通知编号、单位、检查人、接收人、整改负责人、复查人等正式字段关闭自动纠错。

### 5. 首页最近记录摘要

- 首页最近记录此前已有优化：优先展示部位/地点、隐患短句、风险等级和状态，避免长 AI 分析撑满首页。
