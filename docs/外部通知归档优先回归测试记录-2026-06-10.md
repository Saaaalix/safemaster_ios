# 外部通知归档优先回归测试记录（2026-06-10）

## 本轮目标

- PDF / Word / 图片导入后，优先保存为外部文书归档记录。
- 归档字段继续尽量识别：文档类型、发文单位、通知编号、通知日期、整改期限、受检单位、项目名称、摘要、原文和清洗文本。
- 隐患条目、整改要求、法律依据降级为可选参考信息，不作为确认归档的阻断条件。

## 回归路径

### 1. 导入箱草稿核对路径

操作：
- 导入文件后进入导入箱草稿核对页。
- 清空隐患条目。
- 保留归档必填字段完整。
- 点击「确认归档」。

期望：
- 按钮不因隐患条目为空置灰。
- 页面显示「隐患条目未完整识别，不影响归档。归档后可在记录详情中继续补充。」。
- 可保存为外部文书归档记录。

本轮结果：
- 已通过代码核对：`hasBlockingMissingFields` 仅检查归档必填字段，`coreHazardMissingCount` 固定为 `0`。

### 2. 隐患条目不完整路径

操作：
- 识别一份只包含发文单位、通知日期、整改期限等归档字段的文档。
- 不补隐患条目。
- 点击「确认归档」。

期望：
- 允许归档。
- 隐患条目不完整只作为提示，不进入底部「还差」阻断项。

本轮结果：
- 已通过代码核对：识别器在未识别隐患时追加非阻断提示，核对页缺项列表不再加入隐患问题/整改要求。

### 3. 手动识别建档路径

操作：
- 导入箱 -> 更多 -> 识别建档。
- 不填写隐患条目。
- 点击「确认归档」。

期望：
- 允许保存为归档记录。
- 隐患条目分区默认折叠为「可选：识别到的隐患条目」。

本轮结果：
- 已通过代码核对：手动页 `canSave` 不检查隐患条目，隐患条目 UI 已放入可选折叠区。

### 4. 外部通知进入详情页

操作：
- 归档成功后点击「查看归档记录」。
- 进入记录详情页。

期望：
- 外部来源记录不要求点击「确定隐患详情」。
- 没有隐患条目时，仍显示归档来源信息和占位说明。

本轮结果：
- 已通过代码核对：外部来源记录继续按已确认归档处理，详情页不会显示「确定隐患详情」按钮。
